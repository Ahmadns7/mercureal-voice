Install

  1. Download the APK from the latest release.
  2. Allow unknown sources for your browser or file manager. On Android 8+ this is per app: Settings, Apps, the app you opened the file with, Install unknown apps, Allow. The exact path varies by phone brand.
  3. Open the APK and tap Install. If Play Protect warns, choose the option to install anyway, only if you downloaded it from the link above.
  4. Install the speech pack. Voice recognition works best with an offline speech pack. Settings, System, Languages and input, Offline speech recognition, download English (and your language if offered). The app warns on Home if the phone has no offline recognition.
  5. Grant permissions as you use features. Nothing is asked up front beyond the microphone.

Permissions and privacy

Everything runs on your phone. Speech recognition, command parsing, the reminders, the notification reader and the on-device assistant all work on the device.

  • No account, no sign-in, no analytics, no ads.
  • Nothing leaves the phone except the SMS and calls you trigger yourself, and the location text in emergency mode when you trigger it.
  • The smart-mode model is downloaded once, from your consent, then checked with a checksum. You can delete it in the app.
  • Each sensitive permission is asked for only when a feature needs it: microphone, calls, contacts, SMS, location, camera, usage access, notification access and the accessibility service.
